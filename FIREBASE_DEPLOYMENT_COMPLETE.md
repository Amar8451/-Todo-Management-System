## 📋 Next Steps (Deployer Instructions)

### 1. Firebase Setup (One-Time)
- Create Firebase project at https://console.firebase.google.com/
- Enable Firestore Database (Production mode, us-central1)
- Create collections: `tasks` and `activities`

### 2. Get Credentials
- Go to Project Settings > General
- Copy Firebase web app SDK config

### 3. Configure Vercel
- Add 6 Firebase environment variables to Vercel project settings:
  - VITE_FIREBASE_API_KEY
  - VITE_FIREBASE_AUTH_DOMAIN
  - VITE_FIREBASE_PROJECT_ID
  - VITE_FIREBASE_STORAGE_BUCKET
  - VITE_FIREBASE_MESSAGING_SENDER_ID
  - VITE_FIREBASE_APP_ID

### 4. Deploy
- Merge PR #2 to main
- Vercel automatically deploys with Firebase credentials
- Visit deployed URL to verify

## ✨ Key Features

### Firestore Collections
**tasks**
- id: Auto-generated by Firestore
- title: Task title
- description: Task details
- priority: High/Medium/Low
- status: Pending/Completed/In Progress
- category: Development/Marketing/Personal/Design/Finance/Health
- dueDate: ISO date string
- createdAt: Timestamp

**activities**
- id: Auto-generated
- text: Activity description
- timestamp: ISO timestamp
